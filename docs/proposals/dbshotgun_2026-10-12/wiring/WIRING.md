# Wiring the double-barrel shotgun into the mod - PREPARED, NOT APPLIED, NOT RUN

Nothing here is in the mod tree. Line numbers are from the mod tree on 2026-10-12 (recon by reading, not by running).
The gun itself (tik, mesh, clips, rows, sounds) works without any of this when it is given by script
(`$player give models/weapons/coop_dbshotgun.tik` - that is how every harness run got it).

## 1. Offer it to players - switchable, default ON: `coop_dbShotgun`

Smallest hook, one place: `coop_mod/loadoutpick.scr`, label `loadout_finResolve local.player local.slot local.give`
(line 1312; its header calls it "the ONLY authority" at spawn). Insert before line 1315
(`if(local.fid == NIL || local.fid == 0){ end local.give }`):

```
	//[dbshotgun] the double barrel stands in for the trench gun when the player's slot says so
	if( local.give == "models/weapons/shotgun.tik" && getcvar( "coop_dbShotgun" ) != "0" && local.player.flags["coop_dbsPick"] == 1 ){
		end "models/weapons/coop_dbshotgun.tik"
	}
```

and seed `seta coop_dbShotgun "1"` in `coop_defaults.cfg`. `coop_dbsPick` is the per-player choice; where it is set
is the open decision (section 3). Until one of those exists the snippet changes nothing.
