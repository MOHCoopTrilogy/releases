# In-game ESC board (escmenu, 2026-11-10)

User: "beautify the escape menu when in game, make sure the buttons function and add a disconnect button right from
when you hit escape" (+ coordinator review notes, + a SCOREBOARD row because Tab is the weapon wheel).

## What it is
- **One menu, `dm_main`**, shipped by the mod at the retail path `ui/dm_main.urc` (the filesystem returns only ours, so
  there is never a second board under it - the July overlap, bug-720/767/777, came from a second, differently named
  board). Rows for single player, co-op and MP live in that one file, gated by `enabledcvar` on the mode
  (`cg_gametype`, `coop_isCoopSession`, `sv_running`). GENERATED by `hzm-mohaa-coop-mod/docs/tools/gen_escmenu.py`
  (also writes `ui/hzm_escconfirm.urc`); never hand-edit the urc.
- Look: the Armory's palette and type (dark card, row plates, amber underline + hover wash `mpui_glow`), title = the
  map's display name, mode line (`CO-OP // HOSTING`, `MULTIPLAYER // ONLINE`, `CAMPAIGN // PAUSED`), dim behind.
- Rows - SP: RESUME, LOAD / SAVE, OPTIONS, CONTROLS, REPORT A BUG, MAIN MENU, LEAVE MISSION, QUIT GAME.
  Co-op: RESUME, SCOREBOARD, OBJECTIVES, ARMORY, OPTIONS, CONTROLS, SERVICE RECORD, REPORT A BUG, MAIN MENU,
  DISCONNECT, QUIT GAME. MP: RESUME, SCOREBOARD, CHANGE TEAM, SELECT WEAPON, ARMORY, SPECTATE, vote row, OPTIONS,
  CONTROLS, REPORT A BUG, MAIN MENU, DISCONNECT, QUIT GAME. MP rows keep the retail commands verbatim (the MP armory /
  deploy path is untouched). No MP Service Record row: check_mp_isolation clause 7a keeps MP menus/cvars out of coop
  files; MP's record is on the MP ARMORY screen.
- DISCONNECT / QUIT ask first (`hzm_escconfirm`: LEAVE / STAY, QUIT / STAY; a host is told leaving ends the game for
  everyone). LEAVE = `popmenu 0; wait 1; popmenu 0; wait 1; disconnect; wait 5; pushmenu main` (bug-10929). The
  engine writes the player's saves on the way out (`^~^~^ COOPSAVE flush ... why=disconnect|shutdown`).
- SCOREBOARD = `togglescores` (cgame latch on the +scores board; closes on USE, the first ESC, or toggling again; not
  on attack, which would fire). The hold key is still B / pad View (coop_defbinds4.cfg).
