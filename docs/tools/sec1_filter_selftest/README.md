# SEC1 filter self-test

Proves the server-command filter change in `openmohaa-hzm/code/cgame/cg_servercmds_filter.cpp`
(security layer 1) does what it claims **against the real shipped code**, not a transcription
(docs/TRAPS.md T14: a check that cannot fail against the DLL is worse than none).

## What it checks

The harness compiles the **real** engine tokenizer and the **real** filter source, then runs:

- **Attack (a), all writer verbs** — `seta`/`set`/bare `<cvar>`/`append` a command into a coop_
  cvar then `vstr` it: must DROP, each with its exact `^~^~^ COVC VDROP` sub-reason.
- **Name-bus injection** — a server appending a privileged marker (`,ga`/`,nc`/`,3`/`,6`/…) via
  `append name`, `set/seta name`, bare `name`, or through a `vstr`: must DROP (`namebus`).
- **Overflow** (>32 staged writes in one text) and **self-referential `vstr`** (depth): must DROP
  and terminate.
- **Must-PASS coop guards** — marker-free names (`set name Player`, `name John Smith`), the fov/auth
  resends, the armory skin/helmet/finish/gloves markers, admin-set auth keys, the nested commit-gate
  store, and the numeric cleared state (`coop_loASkin 0`).
- **Differential arm** — for each write, the value the **real** `Cmd_TokenizeString2`/`Cmd_ArgsFrom`
  produces is compared to the filter's in-walk model decision, so an append/bare mis-model (e.g.
  append treated as overwrite) is caught.
- **Inventory replay** — every archived value the mod's server-side `vstr`s expand to, swept live
  from the cfg/urc tree plus the script-built shapes: all must PASS (0 drops = zero coop regression).
- **Delta arm** — the same harness is compiled a second time against the committed **pre-SEC1**
  filter (`git show HEAD:`) and must **admit** the attack list, proving the fix is load-bearing.

## Run it

```
docs\tools\sec1_filter_selftest\build.bat
```

Prints `SEC1 SELFTEST: PASS` and exits 0 when both builds behave.

## This is a MANUAL / engine-build step - NOT a build.ps1 gate

It needs the MSVC toolchain (`vcvars64`). A script-only coop build on a shell without MSVC must never
be blocked by a C harness, so `build.ps1` does not call this. (The approved fail-if-missing rule
applies to the Python MP-isolation checkers, not to this.) Run it whenever
`cg_servercmds_filter.cpp` changes, and after adding a new server-`vstr`'d cvar or a new name-bus
marker (a missing marker shows up as a replay drop here, not in a playtest).

## Files

| file | role |
|---|---|
| `gen.py` | emits `real_qshared.inc` / `real_cmd.inc` / `real_filter_{work,head}.inc` from live source |
| `gen_inv.py` | emits `inv.inc` — swept archived + script-built values (regenerated by `build.bat`) |
| `harness.c` | the test driver; compiled twice (patched / head) |
| `build.bat` | regenerate, compile both, run both |

Generated `.inc`, `.exe`, `.obj`, `.log` are build products (see `.gitignore`).
