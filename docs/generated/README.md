# docs/generated — derived documentation
Everything in this directory is a **pure function of the repository state**. It is rebuilt from scratch, never patched. If one of these files is wrong, the fix is in the code, the git history, `.wolf/buglog.json`, or `docs/tools/docgen.py` - never here.

## The split that keeps this doc set alive
| | authored (`docs/*.md`) | generated (`docs/generated/*`) |
|---|---|---|
| written by | a human, or Claude with judgement | `docs/tools/docgen.py` |
| can drift | yes - needs review | **no** - regenerated |
| holds | judgement, causation, war stories, open questions | inventories, indexes, counts |
| examples | `SOURCE_OF_TRUTH.md`, `TRAPS.md`, `DECISIONS.md`, `OPEN.md` | this directory |

The rule: **anything extractable from code, git or buglog.json must be generated.** Hand-maintained inventories rot - that is exactly how `.wolf/anatomy.md` ended at ~2% coverage while promising completeness.

## Files

| file | what it is | source of truth |
|---|---|---|
| `FILEMAP.md` | workspace census + full source index | a fresh sweep of every file |
| `filemap.tsv` | every in-scope file, one row, greppable | same sweep |
| `CVARS_COOP.md` | all `coop_*` cvars: engine default, cfg seed, script sites, ui | `.scr` + `.cfg` + `.urc` + `Cvar_Get` |
| `CVARS_ENGINE.md` | every cvar the engine registers, with default and flags | `Cvar_Get` under `openmohaa-hzm/code/` |
| `SUBSYSTEMS.md` | `coop_mod/` scripts, boot order, coop-integrated maps | `coop_mod/*.scr`, `maps/*.scr` |
| `FIX_LEDGER.md` | every buglog entry, chronological | `.wolf/buglog.json` |
| `FIX_INDEX.md` | **file -> ordered bug ids**, and tag index | `.wolf/buglog.json` |
| `CHRONOLOGY.md` | per-repo history, HEAD, and uncommitted exposure | `git` in all three repos |
| `manifest.json` | sha256 of each generated file + input fingerprint | this generator |

## How to run it

```powershell
python docs\tools\docgen.py build      # regenerate (skips if inputs unchanged)
python docs\tools\docgen.py build --force
python docs\tools\docgen.py check      # exit 1 if these files are stale
python docs\tools\docgen.py status     # fingerprint + staleness, no writes
```

`.wolf/hooks/stop.js` runs `build` at the end of every session. It is a no-op when nothing changed, so the cost is a fingerprint walk, not a rebuild.

## Authored-doc budget
The authored files carry judgement, so they cannot be generated - but they can still rot by accumulation. `.wolf/cerebrum.md` reached 525 KB because its filling rule had no counterweight, and at that size the rule that said to read it was no longer physically satisfiable. Over budget means **merge and prune**, not append.
